# BYK Seri Baskı Pro

Excel’deki seri numarası / barkod listesini okuyup termal etiket yazıcısına basan program.

Geliştirici: **BIYIK.DEV** · Destek: [metin@biyik.dev](mailto:metin@biyik.dev)

---

## İndir

| Bilgisayar | İndirme |
|---|---|
| **Windows** | [Windows kurulumunu indir](https://github.com/metinfarukbiyik/bykseripro/releases/latest/download/BYKSeriBaskiPro_Kurulum.zip) |
| **Mac** | [macOS kurulumunu indir](https://github.com/metinfarukbiyik/bykseripro/releases/latest/download/BYKSeriBaskiPro_macOS.zip) |

---

## Program ne işe yarar?

- Excel’den barkod / seri no listesini alır  
- Etiketi ekranda önizler  
- Xprinter veya TSPL uyumlu termal yazıcıya basar  
- Tek tek seçili satır veya tüm listeyi basabilirsiniz  
- Test baskısı ile yazıcıyı hızlıca deneyebilirsiniz  

Kurulumdan sonra internet gerekmez.

---

## Neler içerir?

- Excel dosyasından etiket okuma  
- Canlı etiket önizlemesi  
- Seçilileri bas / tümünü bas  
- Test baskı (örnek etiket)  
- Barkod tipi ve etiket boyutu ayarları  
- Marka / firma yazısı (üst veya alt)  
- Yazıcı seçimi  
- Ayarları kaydetme  

---

## Windows kurulumu

1. Yukarıdaki **Windows** linkinden zip’i indirin  
2. Zip’i açın  
3. `BYKSeriBaskiPro_Kurulum.exe` dosyasına çift tıklayın  
4. Kurulum klasörünü seçin → **Kurulumu Başlat**  
5. İsterseniz masaüstü / Başlat menüsü kısayolundan açın  

Windows “bilinmeyen uygulama” uyarısı verirse: **Ek bilgi** → **Yine de çalıştır**.

---

## Mac kurulumu

1. Yukarıdaki **Mac** linkinden zip’i indirin  
2. Zip’i açın  
3. `BYKSeriBaskiPro.app` dosyasına çift tıklayın  
   *(veya `KURULUM.command` ile Uygulamalar klasörüne kurun)*  

İlk açılışta engellenirse: uygulamaya **sağ tık → Aç → Aç**.

---

## Yazıcı

- Önerilen: **Xprinter XP-490B** veya TSPL uyumlu termal etiket yazıcısı  
- Yazıcıyı bilgisayara bağlayıp sistemde görünür olduğundan emin olun  
- Mac’te: **Sistem Ayarları → Yazıcılar ve Tarayıcılar** içinden ekleyin  

---

## Excel dosyası nasıl olmalı?

İlk satır başlık, sonraki satırlar etiket verisidir.

| Sütun (örnek) | Anlamı |
|---|---|
| Barkod | Ana barkod / seri no (zorunlu) |
| A-K Barkod | İkinci barkod (isteğe bağlı) |
| ItemNo | Orta metin (isteğe bağlı) |
| ParcaAd | Alt metin (isteğe bağlı) |

Programı açıp Excel’i seçin → önizlemeyi kontrol edin → **Seçilileri Bas** veya **Tümünü Bas**.

---

## Kısa kullanım

1. Programı açın  
2. Excel dosyanızı yükleyin  
3. Yazıcıyı seçin  
4. Önizlemeye bakın  
5. Baskı alın  
6. İsterseniz **Ayarları Kaydet**  

Program içindeki **Kullanım** butonunda da aynı rehber vardır.
