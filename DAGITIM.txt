GitHub Actions (otomatik Mac + Windows paket)
---------------------------------------------
  Tam otomatik — tag / sürüm artırma gerekmez:
  1) Değişiklikleri main’e push et
  2) Actions → “Release packages” sürümü otomatik belirler
       (son tag v1.2.0 → v1.2.1 …), Windows + macOS paketlerini derler
  3) Release “latest” olarak yayınlanır (~10–15 dk)
  Büyük sürüm atlamak için (ör. 1.3.0) yalnız VERSION dosyasını değiştir.
  Yalnız doküman (README, *.md, DAGITIM.txt) değişen push sürüm üretmez.

  Kullanıcı indirme (kalıcı — site butonları, giriş gerekmez):
    https://github.com/metinfarukbiyik/bykseripro/releases/latest/download/BYKSeriBaskiPro_Kurulum.zip
    https://github.com/metinfarukbiyik/bykseripro/releases/latest/download/BYKSeriBaskiPro_macOS.zip
    https://github.com/metinfarukbiyik/bykseripro/releases/latest/download/BYKSeriBaskiPro_Portable.zip

  Paylaşmayın: repo ana sayfa, Releases sayfası, Source code.
  (Repo public; indirme açıktır. Source code’u link olarak vermeyin.)

  Uygulama içi güncelleme (v1.2.0+):
    Program açılışta GitHub “latest” sürümünü sorgular. Yeni sürüm varsa
    “Güncelleme geldi” bildirimi çıkar; “Şimdi güncelle” paketi indirir,
    uygulamayı kapatır, aynı klasöre kurar ve yeniden açar
    (config.json / Excel korunur). Her main push’u yeni sürüm olur.
    Not: v1.1.1 ve öncesi bu özelliği içermez; bir kez elle güncellenmeli.

  Actions (geliştirici):

WINDOWS
-------
Geliştirici:
  BUILD_RELEASE.bat
  (veya GitHub Actions — Windows runner)

Paylaşılacak:
  release\BYKSeriBaskiPro_vX.X.X_Kurulum.zip

Alıcı:
  1) Zip’i açar
  2) BYKSeriBaskiPro_Kurulum.exe → çift tık
  3) Kurulum klasörünü seçer (Gözat / Program Files / kullanıcı klasörü)
  4) “Kurulumu Başlat”
     Program Files seçilirse yönetici onayı istenir.

Varsayılan kurulum klasörü:
  %LOCALAPPDATA%\BiyikDev\BYKSeriBaskiPro
  veya seçilirse: %ProgramFiles%\Biyik.dev\BYKSeriBaskiPro

Kaldırma:
  Windows Ayarlar → Uygulamalar  /  Denetim Masası → Program ekle veya kaldır
  (Yayıncı: Biyik.dev)  veya kurulum klasöründeki KALDIR.bat

SmartScreen uyarısı: “Ek bilgi” → “Yine de çalıştır”
  (Exe dosya özelliklerinde yayıncı: Biyik.dev. SmartScreen’de
   “bilinen yayıncı” için Authenticode kod imzası gerekir.)


macOS
-----
ÖNEMLİ: .app paketi YALNIZCA bir Mac bilgisayarda derlenir.
(Windows’ta üretilen exe, Mac’te çalışmaz.)

Geliştirici (Mac):
  chmod +x *.sh *.command
  BUILD_RELEASE_MAC.command   (veya ./BUILD_RELEASE_MAC.sh)

Paylaşılacak:
  release/BYKSeriBaskiPro_vX.X.X_macOS.zip

Alıcı (Mac):
  1) Zip’i açar
  2) BYKSeriBaskiPro.app’e çift tıklar
     veya KURULUM.command ile /Applications’a kurar

İlk açılışta Gatekeeper:
  Sağ tık → Aç → Aç

Veri (config / Excel):
  ~/Library/Application Support/BiyikDev/BYKSeriBaskiPro

Kaldırma: KALDIR.command  (veya ./KALDIR.sh)

Yazıcı (macOS):
  Sistem Ayarları → Yazıcılar & Tarayıcılar → etiket yazıcısını ekleyin.
  Uygulama baskıyı CUPS ile “raw” gönderir (TSPL).
